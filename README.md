# 作者反盗版软件生成工作区

一套供 Coding AI 使用的提示词与参考资料，帮助作者按自己的需求开发和维护本地优先的反盗版辅助软件。

**维护者：杜十方（DuShifang） · 资料版本：v0.9.4 · 联系邮箱：luyounuan@163.com**

作者可以描述自己的搜索、线索复核、证据整理、投诉辅助和维护需求，由 Coding AI 选择合适的实现。本资料统一业务底线与验收要求，保留个人软件在技术栈、界面、存储和搜索方案上的选择。

## 这份资料如何使用

1. 下载并解压本仓库到一个用于开发作者软件的工作目录；不要将资料目录误当作已经生成的软件。
2. 用能够读取本地文件的 Coding AI 打开该目录。若工具会自动读取 AGENTS.md，它将获得阅读入口；否则请明确让它先读该文件和主准则。
3. 用自然语言说明您的作品范围、所需功能、电脑环境以及是否已有软件。
4. 让 Coding AI 按需求实现、运行和验证软件。已有项目应增量维护，不能用模板覆盖原有代码、配置和数据。

可用的开场说明：

> 请先阅读工作区 AGENTS.md 和主开发准则，检查现有文件，再按我的实际需求开发或维护作者反盗版工具。先确认关键缺口，不默认实现全部参考功能。开发和测试使用虚构资料，不读取或上传我的真实证件、合同和模型密钥。

模型工具及服务由用户自行选择、安装和配置；本仓库不包含模型密钥、Node 安装器、一键 EXE 或已经生成的个人软件。

## 与填表扩展的关系

搜索、线索复核、用户界面、资料保管和结果记录由个人软件负责。需要网页填表或附件辅助时，接入 [作者维权填表助手](https://github.com/DuShifang/author-complaint-assistant) 的共用扩展和本机桥接，不为每位作者重复开发同一套填表执行器。

当前文档对应扩展安装包 **0.3.1**，传输协议 **0.2**，HTTP 的 extensionVersion 仍为 **0.2.0**。扩展源码、安装包与本提示词仓库分别维护。本仓库不包含扩展本体；其商店安装方式以实际审核上架状态为准。

验证码、扫码、签名、声明及最终提交由作者本人完成。仅完成填写或文件选择不能视为投诉成功。
